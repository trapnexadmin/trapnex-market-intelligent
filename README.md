# TRAPNEX Market Intelligence

Retail-first, explainable market intelligence for Indian equities.

## Milestone 1 starter
- Official supplied TRAPNEX logo
- Market ticker
- Nifty Trend Pulse
- Large/Mid/Small Cap Pulse
- Sector Pulse
- Market Breadth
- 10%+ expected-return opportunity screen
- Danger Radar
- Portfolio health
- Market news ticker
- Responsive dashboard shell

All displayed market values are DEMO data. Replace with real provider adapters before production.

## Run
npm install
npm run dev

Open http://localhost:3000
