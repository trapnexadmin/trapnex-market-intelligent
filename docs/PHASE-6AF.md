# Phase 6AF — Portfolio UI

Base: Phase 6AE commit `ee59eb1d45cadefa4c3e1634c9a88eee7ba262d6`.

Builds the `/portfolio` page over the committed portfolio allocation API.

- Editable capital input.
- Risk profile selector.
- Refresh/build allocation actions.
- Allocation table with score, expected return, risk and liquidity context.
- Large/Mid/Small-cap exposure view.
- Sector exposure view.
- Constraint/guardrail display.
- Unallocated capital and warning display.

This UI surfaces model outputs; it does not imply guaranteed returns.
